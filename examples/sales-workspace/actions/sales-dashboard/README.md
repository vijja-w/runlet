# Sales Dashboard

Creates an interactive view of sales by region and product.

## Before you run

- Add `sales.csv` with `date`, `product`, `region`, and `amount` columns.

## How to use

1. Upload or replace `sales.csv` in Files.
2. Click **Run** to refresh the dashboard’s data.
3. Click **Open** to explore the latest results.

## Outputs

- `outputs/data.json` — the prepared data shown by the dashboard.
